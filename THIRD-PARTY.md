# Third-party notices

Track Separator application code is MIT licensed; see `LICENSE`.
Windows builds include Python 3.11, CPU-only PyTorch, Demucs 4.0.1, NumPy,
SoundFile, their required dependencies, and FFmpeg. Their licenses and notices
are retained in the bundle's `notices/` directory. Pinned build versions are
in `build/requirements-lock.txt`.

FFmpeg is a separate command-line executable. Its original `LICENSE`,
`README.txt` with source reference, and build configuration are bundled.
Dependency metadata and license texts are generated by `build/notices.py`.
Do not remove those notices when redistributing.

The `htdemucs_6s` checkpoint is downloaded only after an explicit setup/repair
action from the upstream Demucs repository. Its pinned full SHA-256 is verified
before installation. Processing uses a verified local `--repo`, without remote
model resolution. Model weights do not ship with the app or source archive.

The interface uses system fonts. No piano samples, instruments, VST plugins,
user tracks, or libraries are part of the Track Separator bundle.
